<div class="herm-cell">
<span class="herm-cell-label">Cell 4 &middot; Post Layout</span>
<h3>_layouts/post.html</h3>

<div class="narrative-echo">
The remainder of my long conversation with Claude was spent navigating the complex interaction between GitHub web, GitHub desktop, and Jekyll software/the Notepad++ editor.
</div>

<p>The layout that wraps every post. The conditional <code>{% if page.hermeneutics %}</code> block runs only on posts where the front matter sets that flag. The Liquid <code>where</code> filter performs the join between a post and its matching hermeneutics file by comparing <code>page.slug</code> to the <code>post_ref</code> field in each hermeneutics document.</p>

<pre><code>---
layout: default
---
&lt;article class="post"&gt;
  &lt;header class="post-header"&gt;
    &lt;h1 class="post-title"&gt;{&#123; page.title &#125;}&lt;/h1&gt;
    &lt;p class="post-meta"&gt;{&#123; page.date | date: "%B %-d, %Y" &#125;}&lt;/p&gt;

    {&#37; if page.hermeneutics &#37;}
    {&#37; assign herm = site.hermeneutics | where: "post_ref", page.slug | first &#37;}
    {&#37; if herm &#37;}
    &lt;div class="layer-switcher"&gt;
      &lt;button class="layer-btn active" data-layer="narrative"
              onclick="switchLayer('narrative')"&gt;
        &lt;span class="btn-label"&gt;Narrative&lt;/span&gt;
      &lt;/button&gt;
      &lt;button class="layer-btn" data-layer="hermeneutics"
              onclick="switchLayer('hermeneutics')"&gt;
        &lt;span class="btn-label"&gt;Hermeneutics&lt;/span&gt;
      &lt;/button&gt;
    &lt;/div&gt;
    {&#37; endif &#37;}
    {&#37; endif &#37;}
  &lt;/header&gt;

  &lt;div class="post-content"&gt;
    {&#37; if page.hermeneutics and herm &#37;}
      &lt;div class="layer layer-narrative active" id="layer-narrative"&gt;
        {&#123; content &#125;}
      &lt;/div&gt;
      &lt;div class="layer layer-hermeneutics" id="layer-hermeneutics"&gt;
        {&#123; herm.content &#125;}
      &lt;/div&gt;
    {&#37; else &#37;}
      {&#123; content &#125;}
    {&#37; endif &#37;}
  &lt;/div&gt;
&lt;/article&gt;
</code></pre>

<div class="herm-cell">
<span class="herm-cell-label">Cell 6 &middot; Layer Switcher Script</span>
<h3>JavaScript inside _layouts/post.html</h3>

<p>The script that toggles between the narrative and hermeneutics layers, swaps the button labels to "Hyde" / "Jekyll" when in the hermeneutics view, and applies the <code>.hyde-mode</code> class to the body for dark-mode styling.</p>

<pre><code>&lt;script&gt;
function switchLayer(layer) {
  var narrative = document.getElementById('layer-narrative');
  var hermeneutics = document.getElementById('layer-hermeneutics');
  var btnNarrative = document.querySelector(
    '[data-layer="narrative"] .btn-label');
  var btnHermeneutics = document.querySelector(
    '[data-layer="hermeneutics"] .btn-label');

  if (layer === 'hermeneutics') {
    narrative.classList.remove('active');
    hermeneutics.classList.add('active');
    btnNarrative.textContent = 'Hyde';
    btnHermeneutics.textContent = 'Jekyll';
    document.body.classList.add('hyde-mode');
  } else {
    hermeneutics.classList.remove('active');
    narrative.classList.add('active');
    btnNarrative.textContent = 'Narrative';
    btnHermeneutics.textContent = 'Hermeneutics';
    document.body.classList.remove('hyde-mode');
  }

  var buttons = document.querySelectorAll('.layer-btn');
  buttons.forEach(function(btn) {
    if (btn.getAttribute('data-layer') === layer) {
      btn.classList.add('active');
    } else {
      btn.classList.remove('active');
    }
  });

  document.querySelector('.post-content')
    .scrollIntoView({ behavior: 'smooth' });
}
&lt;/script&gt;
</code></pre>
